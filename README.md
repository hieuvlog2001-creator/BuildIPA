# MB Recreated App

Đây là project Flutter được dựng lại dựa trên `Runner.zip` mà bạn cung cấp.

## Tài khoản mặc định

- Tài khoản: `Admin`
- Mật khẩu: `admin`

## Chạy project

```bash
flutter pub get
flutter run
```

## Build iOS

Trên macOS có Xcode:

```bash
flutter build ios
```

Sau đó mở `ios/Runner.xcworkspace` bằng Xcode để cấu hình Team/Signing và cài lên iPhone.

## Lưu ý

Bản này là project dựng lại, không phải source Flutter gốc được giải mã từ ứng dụng đã build. Phần đăng nhập hiện chạy local với tài khoản mặc định ở trên; API/backend của ứng dụng gốc chưa được khôi phục.
